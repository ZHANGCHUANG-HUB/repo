# 创意策略

提出最多三个明显不同的方向。每个只写名称、一句话概念、适用理由和主要风险；选择最匹配营销目标且最易执行的方向完整展开。

完整策略包含：核心传播命题；“谁在什么场景，因为产品获得什么感受或结果”的一句话创意；3 秒视觉钩子；产品最终记忆点；证明、体验、礼赠、发布、教程或生活方式叙事；场景与道具边界；色彩、材质、光线、构图、节奏；旁白、音乐、环境声与音效；风格负面清单。

先定义一个可持续的“生活世界”：时间段、地点、人物关系、正在发生的日常事件、重复出现的道具和光线母题。产品应自然进入这个世界，而不是让环境成为产品背板。生活方式或情绪内容优先采用“氛围建立 → 环境碎片 → 产品首次出现 → 互动/使用 → 英雄画面 → 细节 → 更深使用 → 情绪回报 → 总结收束”的结构；证明型内容可提高产品露出，但仍保留环境建立与结果场景。

策略中明确：

- 环境承担什么信息，产品承担什么信息，人物承担什么情绪。
- 产品在各镜头中的角色：主角、配角、点缀或无产品。
- 哪些镜头交代空间全貌，哪些镜头提供触感碎片，哪些镜头完成品牌识别。
- 一组镜头只使用一个地点家族、一个时间段家族和一小组重复道具，避免像无关广告拼接。

- 产品识别度弱时优先包装、材质与使用动作。
- 卖点需要证明时优先可见过程与结果。
- 礼赠产品突出开箱、递交、陈列与关系场景。
- 高端产品用克制构图、真实材质与慢节奏，不用金色道具堆砌价值。
- 环境参考图优先提取空间层次、光线方向、色彩、前中后景和生活痕迹；不要只把参考环境虚化成产品背景。
- 参考图只定义相关风格维度，不复制其中品牌、人物或受保护元素。
